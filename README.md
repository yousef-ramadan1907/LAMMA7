# Lamma7 – Landing Page (React + Vite)

## التشغيل
```
npm install
npm run dev      # للتجربة
npm run build    # للنشر (مجلد dist)
```

## التعديل
- كل النصوص (عربي/إنجليزي)، أسماء الأعضاء، اسم الكلية/الجامعة/الدكتور/العميد، ولينكات السوشيال: `src/data/content.js`
- صور الأعضاء: حط الصور في `public/team/` وفي `content.js` اكتب `photo: '/team/اسم-الصورة.jpg'`
- الألوان: متغيرات `:root` في `src/styles.css`
- اللوجو: `public/logo.jpg`
